반복되는 선택과 개선을 통해 하나의 완성된 경험을 만들어갔습니다.

  1. 01
    DIRECTION

    의도를 정하다

    포트폴리오의 방향과 레퍼런스를 정하고,
    보여주고 싶은 감각을 구체화했습니다.

  2. 02
    BUILD

    화면으로 옮기다

    대화로 레이아웃과 코드를 만들고,
    타이포와 반응형 구조를 잡았습니다.

  3. 03
    ART DIRECTION

    이미지의 결을 맞추다

    프롬프트와 결과를 거듭 비교하며
    미드센츄리 아트워크를 제작했습니다.

  4. 04
    INTERACTION

    움직임을 설계하다

    스크롤과 커서에 반응하는 효과를 실험하고,
    속도와 강도를 조절했습니다.

  5. 05
    REFINEMENT

    되돌리고, 다시 다듬다

    어긋난 형태와 색, 불필요한 코드를 덜어내고
    작은 화면의 디테일까지 수정했습니다.

  6. 06
    COMPLETION

    의도를 하나의 경험으로

    코드와 이미지, 움직임의 균형을 맞춰
    디자이너의 의도를 담은 포트폴리오로 완성했습니다.

01 / DEFINING THE IDENTITY

바이브 코딩

사이트의 정체성을 바이브 코딩 포트폴리오로 정하면서 콘텐츠의 중심도 제작자의 판단과 의도로 옮겼습니다.
AI가 제시한 초안은 출발점이었습니다.
문장과 화면이 그 정체성을 충분히 드러낼 때까지 재요청을 거듭하며 결과의 밀도를 높였습니다.

REQUEST SUMMARY
사이트의 정체성을 디자인 포트폴리오에서 바이브 코딩으로 만든 포트폴리오로 바꾸고 싶어.
끊임없는 디자이너의 요구사항을 반영해 목표점에 도달하는 내용을 담아줘.
02 / VISUAL CONCEPT

아트워크 중심의 비주얼

익숙한 디자인 모듈을 조합하는 데서 더 나아가, 화면 자체가 하나의 작품처럼 읽히길 바랐습니다.
미드센츄리의 색과 인쇄 질감, 대담한 도형과 타이포를 바탕으로 형태와 여백의 관계를 조율했습니다.
개별 요소보다 화면 전체의 인상이 선택의 기준이었습니다.

REQUEST SUMMARY
큰 오브젝트와 과감한 타이포를 살려, 완성도 있는 미드센츄리 포스터처럼 만들어줘.
색의 톤과 종이 질감을 맞추고, 형태와 여백의 균형을 다듬어줘.
03 / COMPOSING THE EXPERIENCE

Parallax 레이아웃

레이아웃은 정지된 배치에서 패러랙스로 이어지는 공간으로 확장됐습니다.
바이브 코딩은 섹션 고정과 요소별 이동 거리, 가로 스크롤의 계산을 빠르게 구현하는 데 쓰였습니다.
그 위에서 직접 화면을 보며 시선이 머무는 위치와 전환의 호흡을 다듬었습니다.

REQUEST SUMMARY
스크롤에 따라 도형이 물러나고, 타이틀이 중앙으로 모이도록 해줘.
작품 목록은 가로로 이어지되, 시작과 끝에는 충분히 머무를 여유를 줘.
04 / TESTING THE MOTION

Corsur 인터랙션

물결 커서와 마우스 위치에 반응하는 오브젝트는 화면에 촉감을 더합니다.
여러 효과를 비교하며 부담스러운 왜곡을 덜어내고, 반응의 강도와 따라오는 속도를 조정했습니다.
패러랙스 역시 무엇이 먼저 움직이고 얼마나 천천히 사라지는지까지 직접 판단하며 하나의 흐름으로 정리했습니다.

REQUEST SUMMARY
자잘한 물결이 커서를 천천히 따라오고, 오브젝트는 마우스 위치에 반응하게 해줘.
위성 공전 뒤 도형과 작은 글씨가 순서대로 물러나도록, 움직임에 여유를 줘.
05 / DIRECTING THE AI ARTWORK

AI 아트워크 디렉팅

원하는 이미지는 한 번의 생성으로 얻어지지 않았습니다.
프롬프트의 단어를 고르고 형태와 비례, 색과 질감의 조건을 다시 쓰며 시도를 이어갔습니다.
지나치게 상세하거나 모호한 결과를 걸러내고, 개별 작품의 힘과 컬렉션의 일관성을 함께 갖춘 이미지에 도달했습니다.

REQUEST SUMMARY
큰 형태와 강한 실루엣, 균형 잡힌 여백을 가진 미드센츄리 포스터를 만들어줘.
종이와 잉크의 질감은 절제하고, 디테일과 타이포가 형태를 압도하지 않도록 해줘.
06 / REFINING THE RESULT

만족을 위한 집요함

AI의 첫 제안과 지금의 결과물 사이에는 수많은 질문과 수정이 있습니다.
그 차이는 디자이너가 무엇을 어색하게 보고, 무엇을 지키며, 어디까지 다시 요구했는가에서 생겼습니다.
이 프로젝트에서 AI가 구현의 가능성을 넓혔다면, 디자이너의 집요함은 그 가능성에 고유한 방향과 완성도를 부여했습니다.

REQUEST SUMMARY
전체 화면의 균형과 요소 사이 간격을 다시 확인하고 다듬어줘.
의도한 모습은 유지하면서, 불필요한 코드와 수정하기 어려운 구조를 정리해줘.

Reflection

AI / DESIGN / HUMAN WILL

When more

첫 바이브 코딩 작업으로 화면과 인터랙션, 아트워크를 짧은 시간 안에 구현했습니다. 초기 화면을 지금의 모습까지 발전시킨 속도와 실험의 폭은 바이브 코딩이 열어준 가능성이었습니다.

완성도를 높이는 과정에는 세밀한 개입이 필요했습니다. 어색함을 알아보는 감각, 결과를 고르는 판단, 원하는 모습까지 다시 요구하는 의지가 차이를 만들었습니다. 무엇을 향해 나아가고 어디에서 완성이라 부를지는 AI가 판단할 수 없었습니다.

코드의 정돈과 효율적인 관리 체계는 여전히 숙제입니다. 반복 수정에 드는 노력을 줄이면서도 의도한 품질에 도달하는 방법을 찾아야 합니다. 이제 질문은 무엇을 구현할 수 있는가에서, 무엇을 위해 그 가능성을 사용할 것인가로 이어집니다.
